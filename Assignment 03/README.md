# Assignment 03 – Functions & Modules in Python

This project contains two simple Python programs.

---

## Task 1: Factorial Using Function

The program calculates the factorial of a number using a function.

### How it works:
- A function named `factorial()` is defined.
- The function takes a number as input.
- A loop is used to calculate factorial.
- The result is returned and printed.

### Example:
Factorial of 5 is: 120

---

## Task 2: Math Module Calculations

This program uses Python’s `math` module to perform calculations.

### How it works:
- The user enters a number.
- The program calculates:
  - Square root
  - Logarithm (log base e)
  - Sine (in radians)
- All results are displayed.

### Example:
Enter a number: 25  

Square root: 5.0  
Natural logarithm: 3.2188758248682006  
Sine: -0.13235175009777303
