# Assignment 02 – Control Structures in Python

This project contains two simple Python programs.

---

## Task 1: Even or Odd

The program takes a number from the user and checks whether the number is **even or odd**.

### How it works:
- The user enters a number.
- If the number is divisible by 2, it is even.
- Otherwise, it is odd.
- The result is printed.

### Example:
Enter a number: 7  
7 is an odd number.

---

## Task 2: Sum of Numbers from 1 to 50

This program calculates the sum of numbers from **1 to 50** using a `for` loop.

### How it works:
- A variable is used to store the sum.
- A loop runs from 1 to 50.
- Each number is added to the total.
- The final sum is displayed.

### Output:
Sum of numbers from 1 to 50 is: 1275
